### Svyatoslav Nikulin

Control Engineering student (27.03.04 "Control in Technical Systems"), Ural Federal University,
Yekaterinburg. Interested in feedback control on real hardware: plant modelling, controller design
and running it on microcontrollers.

**Projects**

- [**esp32-maglev**](https://github.com/Taraved/esp32-maglev) — magnetic levitation testbed on ESP32
  for measuring how much closed-loop control quality a neural controller loses when it runs in int8
  instead of float32. Actuator analysis and simulation done; closed-loop measurements in progress.
- [**mk_emul**](https://github.com/Taraved/mk_emul) — STM32F407 (Cortex-M4) desktop emulator,
  course project at UrFU. My part ([#1](https://github.com/LifeStyle28/mk_emul/pull/1),
  [#2](https://github.com/LifeStyle28/mk_emul/pull/2)): Cortex-M4 core with exact interrupt timing
  and FPU context, timers and PWM, HAL/FreeRTOS builds, source-level debugger over GDB, 127 tests.
- [**Q-Control-Optimization**](https://github.com/Taraved/Q-Control-Optimization) — emergency
  reconfiguration of a power-grid substation as a QUBO problem, solved with QAOA and compared with
  the classical optimum.
- [**gost-report-skill**](https://github.com/Taraved/gost-report-skill) — AI-agent skill that turns
  lab code and diagrams into GOST 7.32-2001 compliant .docx reports.

**Tools:** Python, C/C++, ESP32, STM32, Qt, Git, Linux
